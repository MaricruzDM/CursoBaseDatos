6.1 Características Generales

📄 Definición

SQL (Structured Query Language / Lenguaje Estructurado de Consultas) es un lenguaje estándar para definir, manipular y controlar bases de datos relacionales. Fue desarrollado por IBM en los años 70 y estandarizado por ANSI/ISO en 1986.

🔬 Analogía

SQL es como aprender un idioma para hablar con bases de datos. Así como usas español para pedir cosas a personas ("dame el reporte de ventas de enero"), usas SQL para pedir cosas al RDBMS (SELECT * FROM Ventas WHERE mes = 'enero'). La gramática es diferente, pero la lógica es la misma: dices QUÉ quieres.

Características principales de SQL

  • Declarativo: Describes QUÉ quieres obtener, no CÓMO obtenerlo (el optimizador decide el cómo)
  • Estándar: Funciona (con pequeñas variaciones) en MySQL, PostgreSQL, SQL Server, Oracle, etc.
  • Basado en conjuntos: Opera sobre conjuntos de filas, no fila por fila
  • No sensible a mayúsculas: SELECT, select y Select son equivalentes (por convención se escribe en MAYÚSCULAS)
  • Cada sentencia termina con punto y coma (;)

Sublenguajes de SQL

SQL se divide en varios sublenguajes según el tipo de operación:

Sublenguaje Significado ¿Para qué sirve? Comandos principales
DDL Data Definition Language Crear y modificar la ESTRUCTURA de la BD CREATE, ALTER, DROP, TRUNCATE
DML Data Manipulation Language Consultar y modificar los DATOS SELECT, INSERT, UPDATE, DELETE
DCL Data Control Language Controlar PERMISOS y acceso GRANT, REVOKE
TCL Transaction Control Language Gestionar TRANSACCIONES COMMIT, ROLLBACK, SAVEPOINT

💡 En esta unidad nos enfocaremos en DDL y DML

DDL para crear la estructura (CREATE TABLE) y DML para trabajar con datos (SELECT, INSERT, UPDATE, DELETE). Estos son los que más usarás en el curso.

6.2 Creación de Base de Datos y Tablas

Crear una Base de Datos

✅ Sintaxis y ejemplo

-- Crear una base de datos nueva
CREATE DATABASE Escuela;

-- Seleccionar la base de datos para trabajar con ella
USE Escuela;

CREATE DATABASE crea la BD. USE le dice al RDBMS "desde ahora, trabajo en esta BD".

Crear Tablas (CREATE TABLE)

📄 Sintaxis general

CREATE TABLE NombreTabla (
    columna1  tipo_dato  [restricciones],
    columna2  tipo_dato  [restricciones],
    ...
    [restricciones de tabla]
);

Tipos de datos comunes

Tipo Descripción Ejemplo de valor
INT Número entero 42, -7, 1000
DECIMAL(p,s) Número con decimales (p dígitos totales, s decimales) DECIMAL(8,2) → 123456.78
VARCHAR(n) Texto de longitud variable (máximo n caracteres) 'Hola mundo'
CHAR(n) Texto de longitud fija (siempre n caracteres) CHAR(2) → 'MX'
DATE Fecha (AAAA-MM-DD) '2024-03-15'
DATETIME Fecha y hora '2024-03-15 14:30:00'
BOOLEAN Verdadero o falso TRUE, FALSE
TEXT Texto largo (sin límite práctico) Descripciones, comentarios largos

Ejemplo completo: Crear las tablas de una escuela

✅ Creación paso a paso

-- 1. Crear la base de datos
CREATE DATABASE Escuela;
USE Escuela;

-- 2. Crear tabla CARRERAS (primero, porque ALUMNOS la referencia)
CREATE TABLE Carreras (
    CarreraID    INT          PRIMARY KEY,
    Nombre       VARCHAR(80)  NOT NULL,
    Duracion     INT          NOT NULL,
    Coordinador  VARCHAR(100)
);

-- 3. Crear tabla ALUMNOS
CREATE TABLE Alumnos (
    Matricula    VARCHAR(10)  PRIMARY KEY,
    Nombre       VARCHAR(50)  NOT NULL,
    Apellido     VARCHAR(50)  NOT NULL,
    Email        VARCHAR(100) UNIQUE,
    FechaNac     DATE,
    Semestre     INT          CHECK (Semestre >= 1 AND Semestre <= 12),
    CarreraID    INT          NOT NULL,
    FOREIGN KEY (CarreraID) REFERENCES Carreras(CarreraID)
);

-- 4. Crear tabla MATERIAS
CREATE TABLE Materias (
    Clave        VARCHAR(10)  PRIMARY KEY,
    NombreMat    VARCHAR(80)  NOT NULL,
    Creditos     INT          NOT NULL,
    Semestre     INT
);

-- 5. Crear tabla INSCRIPCIONES (relación M:N entre Alumnos y Materias)
CREATE TABLE Inscripciones (
    Matricula    VARCHAR(10),
    Clave        VARCHAR(10),
    Periodo      VARCHAR(10)  NOT NULL,
    Calificacion DECIMAL(4,1),
    PRIMARY KEY (Matricula, Clave),
    FOREIGN KEY (Matricula) REFERENCES Alumnos(Matricula),
    FOREIGN KEY (Clave) REFERENCES Materias(Clave)
);

⚠️ Orden de creación

Cuando usas FOREIGN KEY, la tabla referenciada debe existir primero. Por eso creamos CARRERAS antes que ALUMNOS (porque ALUMNOS referencia a CARRERAS).

Modificar tablas (ALTER TABLE)

✅ Operaciones comunes con ALTER

-- Agregar una columna nueva
ALTER TABLE Alumnos ADD Telefono VARCHAR(15);

-- Eliminar una columna
ALTER TABLE Alumnos DROP COLUMN Telefono;

-- Modificar el tipo de dato de una columna (MySQL)
ALTER TABLE Alumnos MODIFY Email VARCHAR(150);

-- Agregar una restricción
ALTER TABLE Alumnos ADD CONSTRAINT chk_semestre 
    CHECK (Semestre >= 1);

Eliminar tablas y bases de datos (DROP)

✅ Sintaxis

-- Eliminar una tabla (¡CUIDADO! Borra toda la estructura y datos)
DROP TABLE Inscripciones;

-- Eliminar solo si existe (evita error si no existe)
DROP TABLE IF EXISTS Inscripciones;

-- Eliminar toda la base de datos
DROP DATABASE Escuela;

⚠️ DROP es irreversible

DROP TABLE elimina la tabla, sus datos y su estructura permanentemente. No hay "Ctrl+Z". En producción, siempre haz un respaldo antes de ejecutar DROP.

6.3 Selección de la Información (SELECT)

El SELECT es el comando más usado en SQL. Sirve para consultar (leer) datos de una o más tablas. No modifica nada, solo muestra resultados.

📄 Sintaxis básica

SELECT columnas
FROM tabla
[WHERE condición]
[ORDER BY columna [ASC|DESC]]
[LIMIT n];

SELECT básico

✅ Consultas fundamentales

-- Seleccionar TODAS las columnas de una tabla
SELECT * FROM Alumnos;

-- Seleccionar columnas específicas
SELECT Nombre, Apellido, Semestre FROM Alumnos;

-- Valores únicos (sin repetidos)
SELECT DISTINCT CarreraID FROM Alumnos;

Filtrar con WHERE

✅ Condiciones de filtrado

-- Igualdad
SELECT * FROM Alumnos WHERE CarreraID = 1;

-- Comparación numérica
SELECT Nombre, Semestre FROM Alumnos WHERE Semestre > 4;

-- Texto (usar comillas simples)
SELECT * FROM Alumnos WHERE Nombre = 'Pedro';

-- AND: ambas condiciones deben cumplirse
SELECT * FROM Alumnos 
WHERE CarreraID = 1 AND Semestre = 4;

-- OR: al menos una condición se cumple
SELECT * FROM Alumnos 
WHERE CarreraID = 1 OR CarreraID = 2;

-- IN: equivalente a múltiples OR
SELECT * FROM Alumnos 
WHERE CarreraID IN (1, 2);

-- BETWEEN: rango de valores
SELECT * FROM Inscripciones 
WHERE Calificacion BETWEEN 80 AND 90;

-- LIKE: búsqueda de patrones en texto
SELECT * FROM Alumnos WHERE Nombre LIKE 'M%';    -- Empieza con M
SELECT * FROM Alumnos WHERE Apellido LIKE '%ez';  -- Termina en 'ez'
SELECT * FROM Alumnos WHERE Nombre LIKE '_u%';   -- Segunda letra es 'u'

-- IS NULL: buscar valores vacíos
SELECT * FROM Alumnos WHERE Email IS NULL;

-- NOT: negar una condición
SELECT * FROM Alumnos WHERE CarreraID NOT IN (1, 2);

💡 Comodines de LIKE

  • % = cualquier cantidad de caracteres (incluyendo cero)
  • _ = exactamente un carácter

Ordenar resultados (ORDER BY)

✅ Ejemplos

-- Ordenar por nombre (A-Z, ascendente por defecto)
SELECT * FROM Alumnos ORDER BY Nombre;

-- Ordenar por semestre de mayor a menor
SELECT * FROM Alumnos ORDER BY Semestre DESC;

-- Ordenar por múltiples columnas
SELECT * FROM Alumnos ORDER BY CarreraID ASC, Semestre DESC;

Funciones de Agregación

Realizan cálculos sobre un conjunto de filas y devuelven un solo valor.

Función ¿Qué hace? Ejemplo
COUNT() Cuenta filas COUNT(*) = total de filas
SUM() Suma valores SUM(Creditos)
AVG() Promedio AVG(Calificacion)
MAX() Valor máximo MAX(Calificacion)
MIN() Valor mínimo MIN(Calificacion)

✅ Ejemplos de funciones de agregación

-- ¿Cuántos alumnos hay?
SELECT COUNT(*) AS TotalAlumnos FROM Alumnos;

-- Promedio de calificaciones
SELECT AVG(Calificacion) AS Promedio FROM Inscripciones;

-- Calificación más alta y más baja
SELECT MAX(Calificacion) AS Maxima, 
       MIN(Calificacion) AS Minima 
FROM Inscripciones;

-- Total de créditos disponibles
SELECT SUM(Creditos) AS TotalCreditos FROM Materias;

Agrupar resultados (GROUP BY)

📄 Concepto

GROUP BY agrupa filas que tienen el mismo valor en una columna y permite aplicar funciones de agregación a cada grupo.

✅ Ejemplos con GROUP BY

-- ¿Cuántos alumnos hay por carrera?
SELECT CarreraID, COUNT(*) AS NumAlumnos
FROM Alumnos
GROUP BY CarreraID;

-- Promedio de calificación por alumno
SELECT Matricula, AVG(Calificacion) AS Promedio
FROM Inscripciones
GROUP BY Matricula;

-- Promedio por materia, solo materias con promedio > 80
SELECT Clave, AVG(Calificacion) AS Promedio
FROM Inscripciones
GROUP BY Clave
HAVING AVG(Calificacion) > 80;

💡 WHERE vs HAVING

  • WHERE filtra filas individuales ANTES de agrupar
  • HAVING filtra grupos DESPUÉS de agrupar

Consultas con JOIN

✅ Combinar información de varias tablas

-- Mostrar nombre del alumno con nombre de su carrera
SELECT A.Nombre, A.Apellido, C.Nombre AS Carrera
FROM Alumnos A
INNER JOIN Carreras C ON A.CarreraID = C.CarreraID;

-- Mostrar inscripciones con nombre del alumno y nombre de la materia
SELECT A.Nombre, A.Apellido, M.NombreMat, I.Calificacion
FROM Inscripciones I
INNER JOIN Alumnos A ON I.Matricula = A.Matricula
INNER JOIN Materias M ON I.Clave = M.Clave
ORDER BY A.Apellido, M.NombreMat;

-- Alumnos que NO tienen inscripciones (LEFT JOIN + IS NULL)
SELECT A.Nombre, A.Apellido
FROM Alumnos A
LEFT JOIN Inscripciones I ON A.Matricula = I.Matricula
WHERE I.Matricula IS NULL;

Orden de ejecución de un SELECT completo

💡 El RDBMS ejecuta en este orden (no es el orden en que lo escribes)

  1. FROM y JOIN - Determina las tablas fuente
  2. WHERE - Filtra filas
  3. GROUP BY - Agrupa filas
  4. HAVING - Filtra grupos
  5. SELECT - Elige columnas
  6. DISTINCT - Elimina duplicados
  7. ORDER BY - Ordena resultados
  8. LIMIT - Limita cantidad de filas

6.4 Inserción, Actualización y Eliminación de Información

INSERT - Insertar datos

📄 Sintaxis

-- Forma 1: Especificando columnas (recomendado)
INSERT INTO tabla (col1, col2, col3)
VALUES (valor1, valor2, valor3);

-- Forma 2: Sin especificar columnas (debes dar TODOS los valores en orden)
INSERT INTO tabla
VALUES (valor1, valor2, valor3, ...);

-- Forma 3: Múltiples filas a la vez
INSERT INTO tabla (col1, col2)
VALUES (val1, val2), (val3, val4), (val5, val6);

✅ Ejemplos de INSERT

-- Insertar un nuevo alumno (especificando columnas)
INSERT INTO Alumnos (Matricula, Nombre, Apellido, Email, FechaNac, Semestre, CarreraID)
VALUES ('A006', 'Carlos', 'Sánchez', 'carlos@escuela.edu', '2003-07-20', 3, 1);

-- Insertar una nueva materia
INSERT INTO Materias (Clave, NombreMat, Creditos, Semestre)
VALUES ('QUI501', 'Química', 6, 1);

-- Insertar varias inscripciones a la vez
INSERT INTO Inscripciones (Matricula, Clave, Periodo, Calificacion)
VALUES 
    ('A006', 'MAT101', '2024-2', NULL),
    ('A006', 'PRG301', '2024-2', NULL);

💡 Notas sobre INSERT

  • Los textos van entre comillas simples: 'texto'
  • Los números van sin comillas: 42
  • Las fechas van entre comillas: '2024-03-15'
  • Para valores vacíos usa NULL (sin comillas)
  • Si una columna tiene DEFAULT, puedes omitirla en el INSERT

UPDATE - Actualizar datos existentes

📄 Sintaxis

UPDATE tabla
SET columna1 = nuevo_valor1,
    columna2 = nuevo_valor2
WHERE condición;

⚠️ ¡SIEMPRE usa WHERE con UPDATE!

Si olvidas el WHERE, el UPDATE modificará TODAS las filas de la tabla. Este es uno de los errores más comunes y peligrosos en SQL.

-- ¡PELIGRO! Esto cambia TODOS los semestres a 5
UPDATE Alumnos SET Semestre = 5;  -- ¡SIN WHERE! Error grave.

-- Correcto: solo actualiza un alumno específico
UPDATE Alumnos SET Semestre = 5 WHERE Matricula = 'A001';

✅ Ejemplos de UPDATE

-- Actualizar la calificación de un alumno en una materia
UPDATE Inscripciones 
SET Calificacion = 88.5 
WHERE Matricula = 'A001' AND Clave = 'MAT101';

-- Cambiar el email de un alumno
UPDATE Alumnos 
SET Email = 'pedro.garcia@escuela.edu' 
WHERE Matricula = 'A001';

-- Avanzar de semestre a todos los alumnos de Sistemas
UPDATE Alumnos 
SET Semestre = Semestre + 1 
WHERE CarreraID = 1;

-- Actualizar múltiples columnas a la vez
UPDATE Carreras 
SET Coordinador = 'Dr. Nuevo', Duracion = 10 
WHERE CarreraID = 3;

DELETE - Eliminar datos

📄 Sintaxis

DELETE FROM tabla
WHERE condición;

⚠️ ¡SIEMPRE usa WHERE con DELETE!

Sin WHERE, DELETE borra TODAS las filas de la tabla (pero conserva la estructura, a diferencia de DROP).

-- ¡PELIGRO! Borra TODOS los alumnos
DELETE FROM Alumnos;  -- ¡SIN WHERE! Tabla vacía.

-- Correcto: borra solo un alumno específico
DELETE FROM Alumnos WHERE Matricula = 'A006';

✅ Ejemplos de DELETE

-- Eliminar una inscripción específica
DELETE FROM Inscripciones 
WHERE Matricula = 'A006' AND Clave = 'MAT101';

-- Eliminar todas las inscripciones de un periodo
DELETE FROM Inscripciones 
WHERE Periodo = '2024-2';

-- Eliminar alumnos que reprobaron (calificación < 70) en una materia
DELETE FROM Inscripciones 
WHERE Calificacion < 70;

💡 DELETE vs TRUNCATE vs DROP

Comando ¿Qué hace? ¿Se puede deshacer? ¿Conserva la estructura?
DELETE Borra filas (con WHERE, selectivo) Sí (con ROLLBACK) Sí
TRUNCATE Borra TODAS las filas (más rápido que DELETE sin WHERE) No Sí
DROP Elimina la tabla completa No No

Buenas prácticas en SQL

🌟 Tips para escribir buen SQL

  1. Siempre prueba con SELECT antes de UPDATE/DELETE. Si vas a borrar registros, primero ejecuta un SELECT con la misma condición para ver qué se va a afectar.
  2. Usa nombres descriptivos para tablas y columnas (no "t1", "col_a").
  3. Escribe las palabras clave en MAYÚSCULAS y los nombres de tablas/columnas en el formato que elijas (consistente).
  4. Usa aliases (AS) para hacer las consultas más legibles.
  5. Comenta tu código con -- para explicar consultas complejas.
  6. Usa indentación para que las consultas largas sean legibles.
  7. Especifica columnas en INSERT en lugar de confiar en el orden.
  8. Nunca hagas UPDATE o DELETE sin WHERE en producción.

Ejercicio integrador

🎯 Consulta que integra todo lo aprendido

"Mostrar el nombre completo de cada alumno, su carrera, cuántas materias cursa y su promedio de calificaciones, solo para quienes tienen promedio mayor a 80, ordenados del mejor promedio al peor."

SELECT 
    A.Nombre,
    A.Apellido,
    C.Nombre AS Carrera,
    COUNT(I.Clave) AS MateriasInscritas,
    ROUND(AVG(I.Calificacion), 1) AS Promedio
FROM Alumnos A
INNER JOIN Carreras C ON A.CarreraID = C.CarreraID
INNER JOIN Inscripciones I ON A.Matricula = I.Matricula
GROUP BY A.Matricula, A.Nombre, A.Apellido, C.Nombre
HAVING AVG(I.Calificacion) > 80
ORDER BY Promedio DESC;

Esta consulta usa: SELECT con columnas específicas, JOIN (dos tablas), alias (AS), funciones de agregación (COUNT, AVG, ROUND), GROUP BY, HAVING, y ORDER BY. ¡Todo lo de esta unidad en una sola consulta!
