📋 Sobre esta guía

Esta guía está diseñada para darte una base sólida antes de cursar la materia de Bases de Datos. Cada unidad incluye:

  • Definiciones claras - Conceptos explicados de forma sencilla
  • Analogías de la vida real - Para que los conceptos abstractos tengan sentido
  • Ejemplos prácticos - Con tablas, diagramas y código SQL
  • Progresión lógica - Cada unidad construye sobre la anterior

💡 Recomendación de lectura

Lee las unidades en orden. La unidad 1 establece el vocabulario que usarás en todo el curso. Si ya conoces algún tema, puedes saltar directamente al que necesites reforzar.

🌱 Antes de empezar

🔬 ¿Qué es una base de datos en pocas palabras?

Imagina una biblioteca. Los libros son los datos, los estantes son las tablas, las etiquetas del lomo son los índices y el sistema de catálogo (Dewey) es el modelo que organiza todo. Una base de datos es exactamente eso: un sistema organizado para guardar, buscar y gestionar información de forma eficiente.

Prerrequisitos sugeridos

  • Saber usar una computadora y navegar archivos
  • Haber usado alguna hoja de cálculo (Excel, Google Sheets) - te ayudará con la analogía de tablas
  • Lógica básica (verdadero/falso, AND, OR) - no necesitas ser experto
  • Ganas de aprender y paciencia para los conceptos nuevos
